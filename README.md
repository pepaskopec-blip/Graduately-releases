# Graduately

Příprava k maturitě pro macOS, Windows, Linux, Android a iPhone.

Tento repozitář slouží pouze k distribuci instalačních balíčků a automatických aktualizací aplikace **Graduately**.

## Stažení a instalace

Stáhni instalátor pro své zařízení, rozbal zip a spusť ho:

| Platforma | Instalátor | Jak spustit |
| --------- | ---------- | ----------- |
| **macOS (Apple Silicon)** | [graduately-installer-macos.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-macos.zip) | Rozbalit, pravý klik na **Nainstalovat Graduately** → **Otevřít** |
| **Windows (x64)** | [graduately-installer-windows.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-windows.zip) | Rozbalit a spustit; u SmartScreenu **Další informace → Přesto spustit** |
| **Linux (x86_64)** | [graduately-installer-linux.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-linux.zip) | Rozbalit a spustit instalátor |
| **Android (8+)** | [graduately-installer-android.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-android.zip) | Rozbalit, otevřít **Stahnout Graduately.html** a nainstalovat APK |
| **iOS (26+)** | [graduately-installer-ios.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-ios.zip) | Rozbalit, otevřít **Jak nainstalovat Graduately.html** |

Všechny aktuální balíčky najdeš také přímo ve větvi [`builds`](https://github.com/pepaskopec-blip/Graduately-releases/tree/builds).
