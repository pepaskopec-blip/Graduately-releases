# Graduately

**English** · [Česky](#česky)

Maturita exam preparation app for **macOS, Windows, Linux, Android, and iOS**.

This repository distributes the compiled installers, app packages, and automatic updates for **Graduately** (v1.3).

- **Website:** [graduately.skopec.dev](https://graduately.skopec.dev)
- **Privacy Policy:** [graduately.skopec.dev/privacy.html](https://graduately.skopec.dev/privacy.html)

## Download & Install

Download the installer for your platform, unzip it, and run it:

| Platform | Installer | Direct Package | How to install |
| --- | --- | --- | --- |
| **macOS (Apple Silicon, 26+)** | [graduately-installer-macos.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-macos.zip) | [graduately-macos-arm64.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-macos-arm64.zip) | Unzip, right-click **Nainstalovat Graduately** → **Open** |
| **Windows (x64)** | [graduately-installer-windows.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-windows.zip) | [graduately-windows-x64.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-windows-x64.zip) | Unzip and run; on SmartScreen click **More info → Run anyway** |
| **Linux (x86_64)** | [graduately-installer-linux.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-linux.zip) | [graduately-linux-x86_64.AppImage](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-linux-x86_64.AppImage) | Unzip and run the installer (or run the AppImage directly) |
| **Android (8+)** | [graduately-installer-android.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-android.zip) | [graduately-android.apk](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-android.apk) | Download and install the APK directly on your device |
| **iOS (26+)** | [graduately-installer-ios.zip](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-installer-ios.zip) | [graduately-ios.ipa](https://github.com/pepaskopec-blip/Graduately-releases/raw/builds/graduately-ios.ipa) | Unzip and open **Jak nainstalovat Graduately.html** for sideload steps |

## Automatic Updates & Sync

- **Built-in updater:** macOS, Windows, Linux, and Android check the [`builds`](https://github.com/pepaskopec-blip/Graduately-releases/tree/builds) branch automatically and update in-app.
- **Accounts:** Sign in with **Apple** or **Google** in **Settings** on any platform to restore Premium and sync your study progress across devices.

### Automatické aktualizace a účty

- **Vestavěný updater:** Aplikace na macOS, Windows, Linuxu i Androidu sama kontroluje větev [`builds`](https://github.com/pepaskopec-blip/Graduately-releases/tree/builds) a nabídne aktualizaci jedním kliknutím.
- **Účty:** V **Nastavení** se můžeš na všech platformách přihlásit přes **Apple** nebo **Google** pro obnovení předplatného Premium a synchronizaci postupu mezi zařízeními.
